Claude入门指南

Claude 是由 Anthropic 开发的 AI 助手。它可以阅读您的文档、起草和编辑内容、在您的各种工具间协同工作，并与您一起推理解决难题。以下是您第一天需要了解的内容，以及当您逐渐上手后可以前往的地方。

您的第一个提示

只需用日常语言向 Claude 写下您的需求。下面的提示会有所帮助，如果您的请求中有任何不清楚的地方，您可以让 Claude 在开始之前先向您提问。您可以附加文档，为它提供更多参考信息。

示例提示：

我错过了今天早上的计划会议。会议记录已附上。告诉我决定了什么、现在我需要做什么，以及在明天的站会之前我应该跟进什么。请用几条要点概括，方便我在通话间隙阅读。

这个提示为 Claude 提供了什么：

  1. 上下文。 这项工作的目的：在这里，是一场您错过的会议。
  2. 任务。 您想要得到的结果：决定事项、您的行动项，以及需要跟进的内容。
  3. 格式。 长度和形式：几条要点。
  4. 材料。 会议记录已附上，因此 Claude 可以根据实际内容进行处理。

几个可以先了解的控件：

  • 添加文件
  • 连接您的工具
  • 输出
  • 模型

您的第一个提示不必完美无缺。如果答案不太对，直接说出来，Claude 会进行调整。再往下一点，您将设置一个属于您自己的任务，连接您的文件和工具。

Claude 的回复可以是什么样子

Claude 会以任务所需的任何形式作答，而这份形式清单还在不断增加。请求您真正需要的东西——无论是一个简单的答案、一张内嵌绘制的图表、一份演示文稿、一个在对话中制作的设计或文档、一份 Excel 电子表格，还是一份您可以照着做的食谱。Claude 负责制作，您负责把控方向。

设置您的第一个任务

当任务需要时，“+”菜单还提供了一些其他选项：

  • 连接器（Connectors）：让 Claude 能够读取并在您已经使用的应用中执行操作，例如您的邮箱、日历、云盘、聊天工具和 CRM。开启一次，之后每次对话都可以搜索它、引用它，并在您允许的情况下写回它。浏览目录。
  • 网页搜索：在 Free、Pro 和 Max 方案中默认开启。在 Team 和 Enterprise 方案中默认关闭，管理员可以将其开启。当答案应该只来自您的文档时，请将其关闭。
  • Research（研究）：运行多次搜索并返回一份带引用的简报。这需要几分钟时间，请将其留给重大问题使用。
  • Skills（技能）：为您每次都以相同方式完成的工作保存的指令，包括您希望随时调用的语气或格式。在 Claude 桌面应用中，您还可以录制自己完成一次任务的过程，并将其保存为技能。
  • 添加文件夹（桌面应用）：将您电脑上的整个文件夹交给 Claude 读取和保存内容，而不必逐个上传文件。

Claude 会记住什么

一旦您向 Claude 说明了您的项目、您的团队，或您喜欢的工作方式，您就不必再重复解释一遍。有几项功能会将重要信息延续下去，让每次对话都从上一次结束的地方开始：

  • Projects（项目）：一个用于承载某项持续进行工作的空间。添加 Claude 应始终随手可用的文件，写下几行说明（品牌语气、格式、绝不能忘记的事项），项目内的每次对话从一开始就已经了解这些内容。当您发现自己总是重复上传相同的文件或反复解释相同的规则时，就可以创建一个项目。
  • Claude 的指令：在您的设置资料中写下的一段简短说明，Claude 会在每次对话中牢记，例如您是谁、应该假设什么，以及应该如何与您交流。设置一次，便会在各处生效。
  • Memory（记忆）：Claude 在各次对话中记住的关于您的信息，例如您的团队、您的项目，以及您喜欢的工作方式。在设置中开启它，它会随着您的使用逐渐完善；您可以随时查看或编辑它。

聊天窗口之外

大多数人从聊天开始使用。同样的 Claude 也出现在其他一些地方，针对不同类型的工作进行了相应调整。

  • 桌面应用 将同样的聊天功能带到您的电脑上，在 Mac 上还增加了随处可用的快速输入、截图和听写功能。
  • Claude Code 是终端和编辑器中的 Claude，面向工程师和开发者。
  • Claude Design 现在可以从任意对话或侧边栏的 Design 标签页启动。它以画板形式呈现界面、流程和原型，您可以在自己的设计系统中手动编辑。
  • Claude Tag 将 Claude 带入您团队的 Slack 工作区。在频道或话题中 @Claude，它就会在那里执行任务，依据对话内容以及管理员已连接的工具来工作。
  • Claude 还运行在您已经使用的应用程序内部：Excel、Word、PowerPoint、Outlook、Chrome，以及移动端。

向 Claude 询问关于 Claude 的问题

当您不确定某个按钮的作用，或为什么某个答案不尽如人意时，Claude 可以帮您排查问题：

  • 询问某项功能如何运作： “Research 功能是做什么的？我什么时候应该用它而不是网页搜索？”
  • 获得更精准的提示以改进您的输出： “向我提问，了解我想要做什么，然后为我写一个更好的提示。”
  • 截图您不认识的内容： Claude 可以读取图片。放入任意 Claude 界面的截图，询问某个功能的作用。
